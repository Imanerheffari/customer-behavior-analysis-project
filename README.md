# Retail Customer Behavior and Shopping Trends – Data Analytics Project

## 1. Overview

This project focuses on analyzing retail customer behavior and shopping trends to identify purchasing patterns, understand customer preferences, and generate meaningful business insights.

The project follows an end-to-end data analytics workflow, including data loading, Exploratory Data Analysis (EDA), data cleaning, SQL analysis using MySQL, and interactive dashboard development with Power BI.

The objective is to transform raw retail data into actionable insights that can support data-driven business decisions.

## 2. Dataset

**Dataset:** Retail Customer Behavior and Shopping Trends

The dataset contains customer shopping information that can be used to explore purchasing behavior, customer preferences, and retail trends.

The analysis focuses on available attributes such as:
- Customer demographics
- Product categories
- Purchase amounts
- Shopping frequency
- Other available shopping-related attributes
